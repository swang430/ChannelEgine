# S5b：标准 ASC 更新率无损写入限制

日期：2026-11-11；基线：f75648d82ed658a140090fc09118ef3f41d2527c。

## 可观察故障与最小修复

标准导出器按1000.04 Hz计算波形，却把文件头写成1000.0 Hz，导致按文件头读取的
时间轴与计算时间轴不一致。仅在`PropsimASCIIExporter._generate_asc_content`开头
将更新率按现有`.1f`格式生成字符串，再以`float(字符串) == 输入值`严格检查。
不相等抛ValueError，相等则复用同一字符串写头。不用isclose，不修改配置，不自动重采样。

这是当前导出器格式限制，不是仪器只支持一位小数。Propsim User Reference Rev10.2
§21.1–21.1.1印刷p330有26092.1示例，未声明任意精度；NotebookLM查询
`queryb729403259d4`沿已核证据，不据示例扩展协议格式。delay秒/ns属于S6待核，不改。

## 入口、失败传播与边界

静态/动态 × DL/UL × 磁盘/内存ZIP共8个标准入口都通过父类生成方法；
磁盘在open之前检查，拒绝不覆盖已有文件，内存ZIP失败不返回结果。
直接内容生成及单文件写入同样受保护。
`MFSWRawExporter`覆写生成方法及内存ZIP入口，不调用该父类生成方法，因此不受此限制；
不在配置模型、共享张量计算或export入口增加检查，不改Raw扩展名、元数据、时延及波形语义。
CE界面导出已有异常展示，baker异常向上传播；不新增消费者机制或跨仓修改。

修法为收窄输入：删除文件头不可行；改计算率会静默改变用户请求；任意精度格式尚无兼容依据。
保持错误输入拒绝比交付错误时间轴代价更小。数值有效域和空链路原有行为不属于本片。

## 使用限制

1000.0、1000.1、26092.1等能通过`.1f`往返保持原数值的更新率可用。
1000.04、1000.05、160.11076569511297及1000.1的相邻浮点数可能被拒绝。
调用方应显式选择可原样表示的更新率并重新生成；不能仅改文件头。
拒绝不删除既有输出，旧文件存在不代表本次导出成功。
修复不证明整个ASC符合设备文件要求，不涉及仪器加载或实机验收。
